# Notes projet

## Ressources disponibles

### three.js (3D)
La bibliothèque **three.js v0.185.1** est intégrée dans `libs/three/` (build complet + addons `jsm`).
À utiliser pour tout élément 3D sur les sites. Voir `libs/three/README.md` pour l'usage
(import map pour site statique, ou `import 'three'` avec un bundler) et
`libs/three/examples/basic-scene.html` pour un exemple fonctionnel.
